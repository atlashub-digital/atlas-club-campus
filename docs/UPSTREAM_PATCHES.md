# LearnHouse upstream patch log

Cada alteração ao código original (backend ou frontend) deve registrar:
- Upstream URL/tag/SHA fixados e data.
- Arquivo/porquê/porquê não extensão/overrides.
- Tests unit/E2E e screenshots afetadas.
- Potencial conflito com atualização upstream.
- Referência PR/issue/ADR.

Começar vazio. **Não presumir que o fork já foi instalado.**
